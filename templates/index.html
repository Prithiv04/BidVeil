Evaluation integrity

BIDVEIL validates document structure, extracts text ephemerally, and runs deterministic weighted scoring. When an inference provider is configured, evaluation results include provider metadata. Without a provider, evaluations fail with a clear INFERENCE_UNAVAILABLE status.

    What BIDVEIL does

    • Validates file type, size and structure before processing.
    • Extracts text ephemerally — originals are never stored.
    • Sends bid text to an inference provider only for the active evaluation, when configured.
    • Generates a fresh 32-byte nonce per evaluation (replay protection).
    • Deletes temporary files after the request, including failures.
    • Does not intentionally persist uploads, prompts, or responses; does not log tender content.

    Limitations — read before use

    • BIDVEIL cannot guarantee physical memory erasure.
    • Any inference provider's retention and logging policies are outside BIDVEIL's control.
    • Verification proves inference integrity, not data privacy at the provider.
    • Do not submit information unless the provider's terms are acceptable to your organisation.
    • Cleanup is confirmed per-request in the processing log; check it after each run.
